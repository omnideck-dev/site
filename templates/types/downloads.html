Installation

Install and set up omnideck

  1. Install omnideck

    Open the DMG, drag omnideck onto the Applications shortcut, then eject the disk image.

  2. Approve omnideck in Settings

    Open omnideck from Applications. If macOS blocks it, select Done, then open System Settings → Privacy & Security and select Open Anyway.

  3. Confirm with an administrator

    Use an administrator’s Touch ID or password, then confirm Open Anyway if macOS asks once more.

  4. Set up omnideck

    Select Set up omnideck. The app prepares the local runtime for your workbench.

  5. Finish setup

    When setup reports that omnideck is ready, select Open omnideck.

Installation

Install and set up omnideck

  1. Approve the installer

    If SmartScreen opens, select More info, confirm the publisher details, then select Run anyway.

  2. Install omnideck

    Select Next, finish the installer, then open omnideck and select Set up omnideck.

  3. Approve required Windows changes

    Select Yes when User Account Control asks to prepare a required Windows component.

  4. Restart if prompted

    Select Restart now. After you sign back in, omnideck reopens and continues setup automatically.

  5. Finish setup

    When setup reports that omnideck is ready, select Open omnideck.
